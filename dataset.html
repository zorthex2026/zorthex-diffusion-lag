Verified backbone · three-source verification. Each case is positioned using three independent attention signals: Google Trends (operational), Wikipedia pageviews (informational), and Reddit (community, declared qualitative proxy). Figures reflect data as of the observation cut-off: May 2026, with Google Trends CSV snapshots locked and archived. All values are subject to revision · re-verification recommended every 90 days, mirroring the dated and revisable nature of credit ratings. Cases are shown with their verification state (Structural / Observation / Bubble / Pre-dataset). Descriptive only · does not constitute investment advice. Full method: methodology.
◉ Google Trends · operationalWho searches to act now. The metric L is computed here (12 consecutive months ≥25/100). CSV snapshot-locked, archived on GitHub.
◉ Wikipedia · informationalWho reads to understand. Absolute pageviews via Wikimedia API — a corrective to search-index normalization.
◉ Reddit · communityHow a topic is discussed. Declared qualitative proxy (assente / nascente / matura), not a metric.

How to read L. L = t_peak − t_start, in months — the gap between first documented public emergence and sustained mainstream attention. L is stable when the all-time peak is historical; cases whose peak is recent (within the Aug-2025 attention wave) carry a provisional L and are marked OBSERVATION. Where the third factor reveals a B2B / policy-driven phenomenon (operational attention high, informational low), this dual-velocity pattern is declared, not corrected. The internal dataset extends beyond these public cases; pre-dataset and non-stationary cases are retained for completeness but excluded from L averaging.
